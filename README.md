# IMG Collage Editor

사진 콜라주 메이커. 빌드 과정 없는 순수 HTML/CSS/JS라 정적 호스팅에 그대로 올라갑니다.
모든 처리는 브라우저 안에서만 이루어지며, 사진은 어디로도 전송되지 않습니다.

연한 민트 도트 배경 위에 창 하나가 떠 있는 모양입니다. 창틀과 상단바는 반투명이라 뒤 패턴이
비치고, 편집 패널(01·02·03) 안쪽만 불투명하게 두어 작업면은 흐트러지지 않습니다.

<https://xngsuii.github.io/suii-collage/>

## 기능

### 사진 붙이기 — 두 가지 방식

- **원본 그대로** — 사진 원본의 비율을 지킨 채 가로 또는 세로로 여백 없이 이어 붙입니다. 맞닿는 변의 길이를 가장 큰 사진에 맞춰 통일하므로 빈틈이 생기지 않고, 사진이 한 장이면 원본 픽셀 크기가 그대로 남습니다. 캔버스가 브라우저가 감당하기 어려울 만큼 커질 때만 균일 축소합니다.
- **캔버스 비율** — 1:1 · 4:5 · 5:4 · 9:16 · 16:9 · 3:4 · 4:3 · 2:3 중에서 고르거나 직접 입력하고, 12가지 템플릿으로 칸을 나눠 채웁니다. 픽셀 크기도 직접 넣을 수 있고, 한쪽을 바꾸면 비율에 맞춰 나머지가 따라갑니다(16:9에서 가로 1920 → 세로 1080).

각 칸의 사진은 드래그로 위치를, `Alt` + 휠로 확대를 조정할 수 있습니다.
**칸을 두 번 누르면 그 자리에서 사진을 교체합니다.** 빈 칸은 한 번만 눌러도 열립니다.
확대 슬라이더 아래에 **좌우 반전 · 상하 반전 · 회전**이 한 줄로 있습니다. 회전은 누를 때마다
시계 방향으로 90도씩 돕니다.

> 원본 그대로 모드에서 90도로 돌리면 칸 모양도 같이 돌아갑니다(가로 사진 → 세로 칸).
> 그래야 잘리는 곳 없이 칸을 정확히 채웁니다. 돌리거나 뒤집어도 끄는 손 방향과 사진이
> 움직이는 방향은 어긋나지 않습니다 — 화면 기준으로 저장한 이동량을 돌아간 좌표계로 옮겨
> 그립니다.
사진 추가 버튼 아래에 넣은 사진의 썸네일이 뜹니다. 눌러서 그 칸을 고르거나, 빈 칸을 눌러 바로 사진을 넣을 수 있습니다.
**썸네일을 끌면 사진 순서가 바뀝니다.** 끄는 칸은 모양 그대로 떠 있고 나머지가 부드럽게 밀려납니다.

> 썸네일은 포인터 캡처를 쓰지 않습니다. 컨테이너가 포인터를 잡으면 `pointerup` 이 그쪽으로 가면서
> `click` 이 버튼 대신 컨테이너로 떨어져 클릭 선택이 통째로 죽습니다. 끄는 동안만 `document` 에
> 귀를 답니다. 칸 안의 이미지에는 `draggable=false` 와 `pointer-events:none` 을 걸어 두는데,
> 브라우저 기본 이미지 끌기가 시작되면 `pointercancel` 이 날아와 순서 바꾸기가 시작조차 못 합니다.
슬라이더 옆 숫자는 눌러서 직접 입력할 수 있습니다.

### 간격과 테두리

사진 사이 간격, 바깥 여백, 테두리 선(굵기·색상·바깥 테두리 여부)을 조절합니다. 테두리는 기본적으로 보이지 않습니다.

### 효과

흑백 · 세피아 · 웜 · 쿨 · 계조화 · 색수차 중 하나를 고르고 **강도**로 세기를 조절합니다.
**필름 그레인**은 다른 효과 위에 겹쳐 쓰는 것이라 목록에서 빼고 따로 두었으니, 흑백에 그레인을
얹는 식으로 함께 쓸 수 있습니다.

**강도는 효과마다 따로 기억합니다.** 흑백을 0.1 로 두고 웜을 0.5 로 올린 뒤 다시 흑백을 누르면
0.1 로 돌아옵니다.

**사진 선택 / 전체** 두 방식 중 하나로만 겁니다. 둘은 겹쳐 걸리지 않습니다.

- **사진 선택** — 고른 칸에만 겁니다. 스티커도 자기 속성에서 따로 겁니다.
- **전체** — 사진 · 글자 · 도형을 다 그린 뒤 캔버스 전체에 덧입힙니다.
  이때 **사진마다 걸어 둔 효과는 적용되지 않습니다.** 값은 지워지지 않으니 다시
  사진 선택으로 바꾸면 그대로 살아납니다.

효과 묶음은 칸을 고르지 않아도 사진 블록에 늘 떠 있습니다. 전체 효과를 켜 둔 채 선택을 풀면
다시 손댈 방법이 없어지기 때문입니다.

사진과 스티커 효과는 결과를 캔버스에 한 번 구워 두고 값이 바뀔 때만 다시 만듭니다. 드래그하는
동안 매 프레임 다시 계산하지 않으려는 것입니다. 캔버스 전체 효과는 그린 결과 자체가 매번
달라져 구워 둘 수 없으므로 매 프레임 다시 계산합니다 — 계조화만 픽셀을 직접 읽어 조금 무겁습니다.

미리보기는 긴 변 1800px로 줄여 굽고, **내보낼 때만 원본 해상도로 다시 굽습니다.** 슬라이더를
끄는 동안 버벅이지 않으면서 저장한 그림은 또렷합니다.

투명 배경 PNG는 효과를 먹인 뒤 원본 알파로 되돌리므로, 그레인이나 색수차가 피사체 바깥으로
번지지 않습니다.

### 스티커 사진
사진 위에 다른 사진을 스티커처럼 얹습니다. **아웃라인**을 켜면 이미지의 알파 채널을 따라 윤곽선이 그려지므로, 배경이 투명한 PNG는 사각형이 아니라 피사체 모양대로 테두리가 들어갑니다.

### 텍스트

- 웹폰트 6종
  - 산세리프 — 프리텐다드, 본고딕(Noto Sans KR), 조선굴림체
  - 세리프 — 본명조(Noto Serif KR), 나눔명조, 고운바탕
- **웹폰트 사용** — 임베드 코드를 붙여 넣어 폰트를 그때그때 늘립니다(아래 참고)
- 굵기 Light / Medium / Bold. 해당 굵기가 없는 폰트는 그 단계를 고를 수 없습니다.
- 이탤릭, 정렬, 크기, 자간, 행간, 글자색, 글자 외곽선
- 글자 배경 — 없음 / 단색 / **글래스모피즘**(뒤 배경을 실제로 블러 처리), 불투명도·여백·모서리 조절

미리보기에서 **글자를 두 번 누르면 그 자리에서 바로 고쳐 쓸 수 있습니다.** 고치는 동안에는
캔버스에 글자를 그리지 않고 입력창이 대신 보여주므로 겹쳐 보이지 않습니다. Esc 나 바깥을
누르면 닫힙니다.

#### 웹폰트 그때그때 넣기

폰트 선택기 아래 **웹폰트 사용**을 켜면 임베드 코드를 붙여 넣는 칸이 열립니다. 확인을 누르면
폰트 목록의 *웹폰트 (이 창에서만)* 무리에 들어갑니다. 받아들이는 형태는 네 가지입니다.

- `<link href="..." rel="stylesheet">`
- `@import url('...');`
- `@font-face { ... }` 원본
- 주소만 (`https://fonts.googleapis.com/css2?family=...`)

**어디에도 저장하지 않습니다.** 새로고침하거나 창을 닫으면 기본 6종만 남습니다.

폰트 이름은 붙이기 전후의 `document.fonts` 를 비교해 새로 들어온 것을 찾아냅니다. 그래서 구글
폰트가 아니어도 됩니다. 굵기도 `FontFace.weight` 에서 읽어 오므로, 한 굵기만 있는 폰트는
Light·Bold 단추가 잠깁니다. 붙여 넣은 코드를 그대로 페이지에 꽂지는 않고, 링크 주소와
`@font-face` 블록만 뽑아 따로 만든 태그에 담습니다.

한글 폰트에는 이탤릭 자형이 없으므로 이탤릭은 기울임 변환으로 처리합니다.

### 도형

원과 사각형(모서리 반경 조절, 기본은 각진 모서리). 채우기는 단색 / 그라데이션 / 글래스모피즘 중에서 고르고, 외곽선을 따로 넣을 수 있습니다.
그라데이션은 시작·끝 색상마다 투명도를 따로 줄 수 있어 한쪽을 완전히 투명하게 흐리는 것도 됩니다.

### 공통 조작

- 드래그로 이동, 모서리 핸들로 크기 조절, 위쪽 핸들로 회전. 회전은 도(°) 단위로 값을 넣거나 초기화할 수 있습니다.
- 그림자 — 켜고 끄기, 불투명도 · 번짐 범위 · **빛 방향**. 해 모양 손잡이를 옮기면
  그림자가 그 반대쪽으로 집니다(0° 가 위쪽, 시계 방향).
- 캔버스 기준 가로/세로/정중앙 정렬
- 레이어 목록을 끌어 앞뒤 순서를 바꿉니다. 끄는 줄은 모양 그대로 떠 있고 나머지가 부드럽게 밀려납니다.
- 레이어 목록에서 복제(⧉)와 삭제(✕). 복제는 `Ctrl/Cmd + D`로도 됩니다.
- 방향키로 미세 이동(Shift와 함께 누르면 크게), Delete로 삭제, Esc로 선택 해제

속성은 분류별로 접을 수 있고, 열고 닫은 상태는 다른 요소를 골라도 그대로 유지됩니다. 텍스트 입력과 폰트 선택처럼 자주 쓰는 것은 항상 펼쳐져 있습니다.
색상은 견본을 눌러 고르거나 HEX 코드(`#f0a`, `#ff00aa`)를 직접 입력할 수 있습니다.
그림자와 글래스의 테두리·블러 반경은 요소 크기가 아니라 캔버스 크기를 기준으로 잡습니다. 요소를 키워도 테두리가 같이 두꺼워지지 않습니다.

### 미리보기 확대

미리보기 아래 **맞춤 · 50% · 75% · 100%** 버튼으로 배율을 고릅니다. 오른쪽에 지금 배율이 뜹니다.
100% 는 캔버스 1px 이 화면 1px 인 상태입니다. 모바일에서는 두 손가락으로 벌려도 됩니다.
사진을 실제로 키우는 게 아니라 화면만 확대하는 것이라 결과물에는 영향이 없습니다.

`Ctrl`/`Cmd` + 휠도 되지만 브라우저가 먼저 가로채 페이지 전체가 확대되는 경우가 있어,
버튼을 기본 수단으로 두었습니다.

**휠은 화면을 밉니다.** `Shift` 와 함께면 좌우로, 마우스 가운데 버튼으로 끌어도 됩니다.
요소 크기와 사진 확대는 **`Alt` + 휠**입니다 — 확대해 놓고 화면을 옮기려 휠을 굴렸을 때
사진이 확대돼 버리던 문제 때문에, 같은 제스처가 상황마다 달라지지 않도록 역할을 갈랐습니다.

### 그리드와 스냅

미리보기 아래에서 켭니다. 칸 수를 직접 넣어(예: 3 × 3) 캔버스를 나누고, 스냅을 켜면 요소를 끌 때 그리드 선과 캔버스 중앙에 달라붙습니다.
그리드 선은 밝은 사진과 어두운 사진 어느 쪽에서도 보이도록 흰 밑선 위에 회색 선을 얹어 그립니다.
그리드는 안내선이라 미리보기 위에만 그려지고 내보낸 이미지에는 남지 않습니다.

### 내보내기

PNG · JPEG · WEBP. JPEG와 WEBP는 품질을 조절할 수 있습니다.

## 로컬에서 실행하기

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 서버가 필요합니다.

```sh
npx serve .          # 또는
python -m http.server 8000
```

## 배포할 때

`index.html` 안의 `?v=21` 을 전부 같은 숫자로 올린 뒤 푸시하세요.
CSS와 JS 모듈이 한꺼번에 새로 받아집니다. 모듈 경로는 임포트 맵으로 묶어 두어 버전이 한 곳에만 적혀 있습니다.

깜빡하면 브라우저가 옛 파일을 최대 10분(GitHub Pages 의 `max-age=600`)까지 계속 씁니다.
사파리는 이 캐시를 특히 오래 붙잡고 있어서, 예전에 확대하면 사진이 한쪽으로 늘어나는 문제가 있었습니다.

## 구조

```
index.html
manifest.webmanifest  홈 화면 추가용 웹 앱 매니페스트
css/
  style.css     레이아웃과 컴포넌트
  fonts.css     구글 폰트로 제공되지 않는 웹폰트(@font-face)
js/
  state.js      상태, 템플릿·비율·폰트 정의, 사진·레이어 생성과 복제
  effects.js    흑백·세피아·웜·쿨·계조화·색수차·그레인 (결과를 구워 두고 재사용)
  webfonts.js   임베드 코드로 폰트를 임시로 늘린다 (새로고침하면 사라짐)
  geometry.js   캔버스 크기와 칸 계산, 좌표 변환, 히트 테스트, 스냅
  render.js     캔버스 그리기 (사진·텍스트·도형·스티커·글래스·그리드)
  files.js      파일 선택과 이미지 로딩
  ui.js         좌우 패널과 속성 편집
  main.js       마우스·키보드 조작과 초기화
icons/
  icon.svg      아이콘 원본(이 좌표대로 PNG 를 다시 그린다)
  *.png         apple-touch-icon 180 · 192 · 512 · 1024 · favicon
tools/
  make-icons.ps1  icon.svg 와 같은 도형을 PNG 로 굽는다
```

## 모바일

좁은 화면에서는 세 패널이 01 / 02 / 03 탭으로 바뀌어 한 번에 하나씩 보입니다. 처음에는 미리보기가 열립니다.

## 홈 화면에 추가하기

아이폰 사파리에서 공유 → **홈 화면에 추가**를 누르면 주소창 없이 앱처럼 열립니다.
안드로이드 크롬도 매니페스트를 읽어 같은 방식으로 설치됩니다.

아이콘은 모서리가 둥근 사각형을 크기가 서로 다른 네 칸으로 나눈 모양입니다.
균일한 격자 대신 칸 크기를 일부러 다르게 둔 건, 이 앱이 비율이 다른 사진을 여백 없이
붙이는 도구라서입니다. 왼쪽 위 칸을 검게 채운 건 앱의 패널 탭(01|LAYOUT) 모양과
닮게 하려는 것입니다.

아이콘을 고치려면 `icons/icon.svg` 를 손보고 `tools/make-icons.ps1` 안의 같은 상수를
맞춘 뒤 스크립트를 실행하세요(윈도우 PowerShell, 별도 설치 없이 `System.Drawing` 사용).

```powershell
powershell -File tools\make-icons.ps1
```

> 스크립트는 주석까지 전부 ASCII 로 적혀 있습니다. Windows PowerShell 5.1 은 BOM 없는
> UTF-8 파일을 ANSI 로 읽어서, 한글 주석을 넣으면 뒤따르는 변수 대입이 조용히 사라집니다.

**주의** — 홈 화면 앱은 사파리와 캐시가 분리돼 있고 주소창이 없어 새로고침이 어렵습니다.
배포 후 반영이 안 되면 홈 화면 아이콘을 지웠다가 다시 추가하는 게 가장 확실합니다.
