# suii collage

간단한 사진 콜라주 메이커. 순수 HTML/CSS/JS로만 만들어서 별도 빌드 없이 정적 호스팅으로 바로 돌아갑니다.

## 사용법

1. 위쪽에서 레이아웃(분할 방식)을 고릅니다.
2. 빈 칸을 눌러 사진을 넣습니다.
3. 사진이 들어간 칸은 드래그로 위치를 옮기고, 휠/핀치로 확대할 수 있습니다.
4. 간격, 배경색을 조절합니다.
5. "이미지로 저장"을 눌러 PNG로 내려받습니다.

모든 처리는 브라우저 안에서만 이루어지며, 사진은 어디로도 전송되지 않습니다.

## GitHub Pages로 열어보기

1. 저장소 Settings → Pages
2. Source를 "Deploy from a branch"로, Branch를 `main` / `root`로 설정 후 저장
3. 잠시 후 `https://xngsuii.github.io/suii-collage/` 에서 접속 가능
