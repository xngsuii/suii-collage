# suii collage

사진 콜라주 메이커. 빌드 과정 없는 순수 HTML/CSS/JS라 정적 호스팅에 그대로 올라갑니다.
모든 처리는 브라우저 안에서만 이루어지며, 사진은 어디로도 전송되지 않습니다.

## 기능

### 사진 붙이기 — 두 가지 방식

- **원본 비율** — 사진 원본 비율을 그대로 유지한 채 가로 또는 세로로 이어 붙입니다. 캔버스 크기는 사진에 맞춰 결정됩니다.
- **캔버스 비율** — 1:1 · 4:5 · 5:4 · 9:16 · 16:9 · 3:4 · 4:3 · 2:3 중에서 고르거나 직접 입력하고, 12가지 템플릿으로 칸을 나눠 채웁니다.

각 칸의 사진은 드래그로 위치를, 휠로 확대를 조정할 수 있습니다.

### 간격과 테두리

사진 사이 간격, 바깥 여백, 테두리 선(굵기·색상·바깥 테두리 여부)을 조절합니다. 테두리는 기본적으로 보이지 않습니다.

### 스티커 사진

사진 위에 다른 사진을 스티커처럼 얹습니다. **아웃라인**을 켜면 이미지의 알파 채널을 따라 윤곽선이 그려지므로, 배경이 투명한 PNG는 사각형이 아니라 피사체 모양대로 테두리가 들어갑니다. 그림자도 켤 수 있습니다.

### 텍스트

- 웹폰트 6종 — Pretendard, 본고딕(Noto Sans KR), IBM Plex Sans KR / 본명조(Noto Serif KR), 나눔명조, 고운바탕
- 볼드, 이탤릭, 정렬, 크기, 자간, 행간, 글자색
- 글자 배경 — 없음 / 단색 / **글래스모피즘**(뒤 배경을 실제로 블러 처리), 불투명도·여백·모서리 조절

한글 폰트에는 이탤릭 자형이 없으므로 이탤릭은 기울임 변환으로 처리합니다.

### 도형

원과 사각형(모서리 반경 조절). 채우기는 단색 / 그라데이션(두 색상 + 각도) / 글래스모피즘 중에서 고르고, 외곽선을 따로 넣을 수 있습니다.

### 공통 조작

모든 요소는 드래그로 이동, 모서리 핸들로 크기 조절, 위쪽 핸들로 회전할 수 있습니다.
방향키로 미세 이동(Shift와 함께 누르면 크게), Delete로 삭제, Esc로 선택 해제.

### 내보내기

PNG · JPEG · WEBP. JPEG와 WEBP는 품질을 조절할 수 있습니다.

## 로컬에서 실행하기

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 서버가 필요합니다.

```sh
npx serve .          # 또는
python -m http.server 8000
```

## GitHub Pages

1. 저장소 Settings → Pages
2. Source를 "Deploy from a branch", Branch를 `main` / `root`로 설정 후 저장
3. 잠시 후 https://xngsuii.github.io/suii-collage/ 에서 접속

## 구조

```
index.html
css/style.css
js/
  state.js      상태, 템플릿·비율·폰트 정의, 레이어 생성
  geometry.js   캔버스 크기와 칸 계산, 좌표 변환, 히트 테스트
  render.js     캔버스 그리기 (사진·텍스트·도형·스티커·글래스)
  files.js      파일 선택과 이미지 로딩
  ui.js         좌우 패널과 속성 편집
  main.js       마우스·키보드 조작과 초기화
```
